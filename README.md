# SmartDesk-Android

SmartDesk v7.5.1 – meeting minutes (MoM) app, phone-ready web version.

- Open the GitHub Pages link on a phone, then **Add to Home Screen** (iPhone: Share → Add to Home Screen; Android: ⋮ → Install app / Add to Home screen).
- Notes, attendees, passwords and API keys are stored only in each phone's browser. Nothing you type is saved to this repository.
- Move notes between laptop and phone with **Settings → Backup & restore**.
